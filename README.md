A modern point-of-sale (POS) and bespoke measurement tracking system designed for tailoring shops and garment ateliers. Handles client body measurements, order slips, delivery dates, and payment balances.

---

## 🌟 Features

- **📏 Precision Measurement Profiles**: Record detailed measurements for Shirts, Pants, Panjabi, Suits, and Traditional attire.
- **🧾 Instant Order Slip Export**: Generate printable and shareable graphic receipts via `html-to-image` and `html2canvas`.
- **⏰ Order Status Tracking**: Track workflow from Cutting → Stitching → Ready for Trial → Delivered.
- **💰 Advance & Balance Ledger**: Record advance deposits and calculate due balance upon delivery.

---

## 🚀 Getting Started

```bash
git clone https://github.com/morshedkoli/molla-tailors.git
cd molla-tailors
npm install
npm run dev
```
